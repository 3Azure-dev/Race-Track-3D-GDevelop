# Race Track 3D (GDevelop)

A 3D lap-racing game made in GDevelop 5. Drive a physics-based car around a track
built from a modular road kit and try to beat your best lap time.

## Features
- 3D physics car handling with handbrake (GDevelop Physics 3D)
- Third-person chase camera
- Track built from modular road pieces: curves, bends, slants, bridges, roundabouts
- Lap counter, lap timer and best-time tracking
- Raycast-based collision checks
- Speedometer UI and a power-up pickup
- Swaying trees and roadside props
- Win screen showing your lowest time

## Built with
GDevelop 5 (3D, event sheets)

## Controls
- Accelerate / Brake: W / S
- Steer: A / D
- Handbrake: Space
